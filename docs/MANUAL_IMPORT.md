# マニュアル（Notionの取り込み）メモ

## できていること（アプリ側）
- `/manual`（ホームの「マニュアル」）: 一覧・さがす・ページ表示。トグル、表、画像、YouTube再生、PDF、コールアウト、列、チェックに対応。
- 権限（DBで判定・`db/migrations/0013_manual.sql`）: ページごとに「見られる最低レベル」「書き込める最低レベル」「お店で分ける」「本人（見られる）」「評価をつけられる人も書ける」。決められるのは管理者だけ（ページ下の「⚙ このページの設定」。下のページ全部にもまとめて設定できる）。
- 技術評価: スタッフ画面（管理者）の「技術評価をつけられる人にする」＝`memberships.can_evaluate`。表のマス・チェックはそのまま入力でき、自動保存。書き込みは「だれが・いつ」が記録される（ページ下の記録）。
- 取り込み: `lib/manual/import.ts`（同じ取り込み元IDなら更新。画像は縮小して、同じものは1つだけ保存）、`scripts/manual-import.ts <json> [--prod]`。本番はTCPで直接つなげないため、Neon の HTTPS(`scripts/neon-http.ts`)を使う。`MANUAL_DB_URL` はNeon APIの connection_uri から取る（値は表示しない）。
- 取り込みJSONの形: `[{sourceId, parentSourceId, title, icon, markdown(Notion拡張マークダウン) または blocks, ownerName, storeName, minLevel, editLevel, evaluatorsEdit}]`。

## 取り込み元の範囲
Notion「株式会社ALBUM」の6ページ: ２６年営業マニュアル / ２６年教育マニュアル / 動画関連 / ATENA天神 / ATENA六本松 / ATENA福津。
「原本ページ（触らないで）／バックアップ」の複製は取り込まない。個人用（習慣管理・Instagramコンサル・マイリンク）は対象外。
ATENA天神などの下には、スタッフ個人の評価ページ（「２６年 山田伊紗」など）があり、技能ごとに「査定者／タイム／点数 × 10回」の表と、シャンプーチェックなどの評価DB（項目 × 1〜10回目の点数1〜5＋コメント）が入っている。DBは `table` ブロック（`choices` で点数の選択肢）に変えて入れる。個人ページは `ownerName`（名前で本人を探す）と `storeName`、`evaluatorsEdit:true` を付ける。

## ランクと名前での権限（0014・公開済み）
- スタッフにランク（アシスタント／スタイリスト）。管理者が「スタッフ」画面で決める。`memberships.rank`。
- ページの権限は、レベル・お店・本人・**ランク（見られる／書き込める）**・**名前（個別の許可。見るだけ／書き込みも）**・評価をつけられる人（スタイリスト、または名前で指定した人）の組み合わせ。管理者がページの「⚙ 設定」でいつでも変更できる（下のページ全部にもまとめて設定可。名前の個別許可は、まとめ設定の対象外）。
- ユーザーの決定: マニュアル（教育・営業・動画）は**全員が見られる**。**評価はスタイリストがつける**。**帰りのチェック表はそのお店の全員が書く**。**売上・議事録は管理者だけ**。これまでNotionで名前ごとに権限を付けていたものは、名前での許可で引き続き可能。

## 取り込み時の初期設定（この決定のとおり）
- 教育マニュアル・営業マニュアル・動画関連: min_level=1, edit_level=4。
- スタッフ個人の評価ページ（ATENA天神など）: store=そのお店, owner=本人, evaluatorsEdit=true（スタイリストが書く）, edit_level=4, min_level=3（本人・同じお店の店長以上・管理者）、スタイリストも見られるよう view_ranks=['stylist']（ほかのお店のスタイリストも見られる点は、ユーザーに確認）。
- 帰りのチェック表: store=そのお店, min_level=1, edit_level=1（お店の全員が書く）。
- 売上DB・スタイリストミーティング議事録・1on1: min_level=4。

## まだの作業
1. Notionの中身の取り出し。MCPコネクタで1ページずつ読むと、画像（営業マニュアルだけで約138枚）の写し間違い・時間がかかるため、次のどちらかで:
   - ユーザーがNotionで「書き出し→HTML（サブページを含める・すべて）」したZIPを添付 → HTML→ブロックの変換器を作る。
   - NotionのAPIの鍵（`NOTION_API_KEY`）を環境に入れ、`api.notion.com` を許可 → APIのブロックJSON→ブロックの変換器を作る（再取り込みも簡単）。
2. 権限の写し: Notionの共有設定はMCPから読めないため、ユーザーに聞く（誰がどのページを見られる／書ける、スタイリスト＝評価をつける人は誰か）。初期値は「見られる=全員(営業・教育)、個人ページ=本人・店長以上・管理者」「書ける=管理者だけ」。
3. 売上・議事録・1on1のような個人情報は、管理者だけ(min_level=4)にしてから取り込む。

## 注意
- 取り込み用のNotionの画像アドレスは5分で切れる。取り出したらすぐ保存する。
- 無料のNeonは0.5GB。画像は幅1600px・WebPに縮小して保存する。
