# 公開の手順（無料）

ねらい: **月額0円**で、みんなのスマホで使えるようにする。

使うもの（どちらも無料・クレジットカード不要）
- **Neon** … データをしまう場所（データベース）
- **Render** … アプリを動かす場所

所要時間: 30分くらい。

---

## 手順1: Neon（データをしまう場所）を作る
1. ブラウザで Neon（ニオン）のサイトを開き、「Sign up」（登録）を押す。Google か GitHub のアカウントでログインできる。
2. 「Create project」（プロジェクトを作る）を押す。
   - 名前: `album`
   - 地域（Region）: 日本にいちばん近い「Asia Pacific」（シンガポールなど）を選ぶ。
   - Postgres のバージョン: 初期のままでよい。
3. 作り終わると「Connection string」（接続用の文字列）が出る。
   - `postgresql://` で始まる、長い文字列。
   - 「Show password」を押して、パスワードも見える状態にして、**全部コピー**する。
   - この文字列は、パスワードを含むので**人に見せない**。

## 手順2: Render（アプリを動かす場所）に公開する
1. Render のサイトを開き、「Get Started」→ **GitHub でログイン**する。
2. GitHub へのアクセス許可の画面が出たら、このアプリのリポジトリ（`sn4k9ty5yd-ops/-`）を許可する。
3. 「New +」→「**Blueprint**」を選ぶ。
4. リポジトリを選び、ブランチは `claude/wonderful-wozniak-ugiono` を選ぶ。
5. 設定を読み込むと、`DATABASE_URL` を入れる欄が出る。ここに、**手順1でコピーした文字列を貼りつける**。
6. 「Apply」（または「Deploy」）を押す。数分で、公開される。
7. 公開されると、`https://album-system-◯◯◯.onrender.com` のようなアドレスが出る。これが、みんなが使うアドレス。

## 手順3: 最初の設定（会社・5店舗・管理者を作る）
1. Render の画面で、このサービスの「Environment」（環境変数）を開き、`SETUP_KEY` の値（長い文字）をコピーする。
2. ブラウザで、`https://（あなたのアドレス）/setup` を開く。
3. 合言葉の欄に、さっきの `SETUP_KEY` を貼る。会社ID・会社名・管理者の名前・社員番号を確認して、「初期設定をする」を押す。
4. 画面に出る **管理者のパスコード**を、**その場で控える**（二度と表示されない）。
5. この `/setup` の画面は、最初の1回しか動かない。

最初に作られるお店: ATENA／ATENA六本松／ATENA福津／Organ／ATENA AVEDA SAKURAMACHI。あとから「⚙ 店舗の編集」で変えられる。

## 手順4: 使いはじめる
1. ログイン画面で、会社ID・社員番号・パスコードを入れてログインする。
2. 「スタッフ」の画面で、店長・シフト担当・スタッフを登録する（登録すると、その人のパスコードが1度だけ表示される。本人に伝える）。
3. 「シフト期間」で期間を作り、希望休の受付を始める。
4. 商品は「商品」の画面で、Excelからコピーしてはりつけて登録できる。

## iPhone のホーム画面に置く
1. iPhone の **Safari** で、アプリのアドレスを開く。
2. 画面の下の「共有」ボタン（四角から矢印が出るマーク）を押す。
3. 「ホーム画面に追加」を押す。
4. ホーム画面に「ALBUM」のアイコンができる。次からは、アプリのように開ける。

---

## 知っておくこと
- **Render の無料プランは、15分使われないと「寝る」。** 寝ているあとの最初のアクセスは、30秒〜1分ほど待つ。
  - 対策（任意）: UptimeRobot（無料）で、5分ごとに `https://（あなたのアドレス）/api/health` を見に行く設定をすると、寝にくくなる。
- **バックアップ**: 管理者でログインして「設定」→「バックアップをダウンロード」。月に1回くらい保管しておくと安心。個人情報を含むので、安全な場所に保管する。
- **無料の条件は、変わることがある。** 数年後に、月に数千円かかる可能性がある。変わるときは、先に確認する。
- パスコードを忘れた人は、オフィス（管理者）か店長が、「スタッフ」の画面で再発行する。

## 困ったとき
- 公開に失敗した: Render の「Logs」（ログ）の画面の、赤い文字を教えてください。
- 「合言葉が違います」: `SETUP_KEY` を、コピーし直す（前後の空白に注意）。
- ログインできない: 会社ID・社員番号・パスコードを確認。5回まちがえると15分ロックされる。管理者に連絡して、パスコードを再発行してもらう。
